### 🐞 Bug Fixes

- Fix "waterfall large" items crashing or degrading into overly tall cards when cover dimensions are missing (local favorites, history, etc.): aspect ratio calculation now falls back to a default ratio instead of producing NaN/Infinity
- Fix distorted item heights in normal waterfall mode for small images / missing dimensions (raw pixel heights were used as logical heights); heights are now always computed proportionally from the column width with the 1:2 clamp kept

- Waterfall lists no longer delete/re-register item controllers on every rebuild; registration only happens when the underlying data object actually changes, reducing registry churn on refresh
