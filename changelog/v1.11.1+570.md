# Eros-FE v1.11.1

This release improves web sign-in reliability and verification handling.

- Clear stale sign-in cookies before loading the sign-in page. Offer a retry if cleanup fails.
- Reset verification-window and Ex-access retry busy states even when navigation or verification raises an error.
- Distinguish web sign-in from security verification, and improve embedded browser layout and controls across platforms.
- PR: [#7](https://github.com/boitar/eros_fe/pull/7)

本次修复网页登录和安全验证流程：

- 先清理旧登录 Cookie，再打开网页登录页；清理失败时可重试。
- 验证窗口或里站访问重试异常后，恢复按钮状态，避免操作被锁住。
- 区分「网页登录」与「安全验证」，并修正多平台内置浏览器布局和交互。

详细说明见 [README_cn.md](../README_cn.md) 和 [PR #7](https://github.com/boitar/eros_fe/pull/7)。
